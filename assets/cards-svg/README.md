# Card image sources

Unmodified SVG sources of the card faces served from `public/cards/`:
**Vectorized Playing Cards 1.0** by **Chris Aguilar**, licensed under the
GNU LGPL v3.0. See `public/cards/README.md` for where they come from and
`public/cards/LICENSE-LGPL-3.0.txt` for the license.

They are kept here, rather than served, because the app displays the PNG
renderings: these SVGs have no `viewBox` and draw the card on a larger page,
so they don't scale to the card slot.
